1-Що вийшло зробити
Шифрування та дешифрування тексту шифром Цезаря
Робота з ENCRYPT / DECRYPT / BRUTEFORCE
Циклічний зсув по алфавіту
Режим brute-force з автоматичним підбором ключа
Автоматичне створення вихідних файлів з мітками

2-Що НЕ вийшло зробити
Повноцінний класичний частотний аналіз зі статистичним файлом

3-Особливості проекту
Підтримка кількох алфавітів - EN, CYRILLIC, SYMBOLS
Автоматичне визначення максимального зсуву
Збереження форматування тексту

4-Цікаві рішення
Евристичний brute-force (score-функція замість частотних таблиць)
Dependency Injection для основних компонентів
Автоматичне очищення старих brute-force файлів

5-На що звернути увагу при перевірці
Логіку brute-force та визначення ключа
Роботу з іменами вихідних файлів
Архітектуру та розділення відповідальностей
